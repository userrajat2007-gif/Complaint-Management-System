Complaint Management System

Project Description

The Complaint Management System is a Python-based project designed to register complaints, assign categories, view complaint details and update complaint resolution status.

Technologies Used

* Python
* SQLite
* Object-Oriented Programming

Features

1. Register a complaint.
2. View all complaints.
3. Search complaints using Complaint ID.
4. Update complaint status.
5. Store complaint records in a database.
